# I1 — RESULT 2026-11-19: simulated TLM extraction on the contact-doping profile

**Run:** `run_tlm_extraction.py` imports `src/graphene_contact_doping_model.py` unchanged. For five physisorbed metals it uses the calculated (111) work functions of Khomyakov et al., PRB 79, 195425 (2009), Table I ([doi:10.1103/PhysRevB.79.195425](https://doi.org/10.1103/PhysRevB.79.195425)), with W0 = 5.4 eV. These are the inputs I2 validated. n_bulk is 2×10¹⁶ m⁻², the src on-state value.
- Device: two identical contacts at x = 0 and x = L. The excess density from each contact is superposed linearly on the src profile: n(x) = n_b + (n_c − n_b)[f(x) + f(L − x)], with f = 1/(1 + x/λ) and λ = 250 nm.
- R_tot(L)·W = ∫₀ᴸ dx/σ(n(x)), using the src puddle-regularised Drude σ. The interface term R_int is set to 0, because it only shifts the intercept.
- A straight line is fitted to 8 lengths in a TLM window, giving R_c,TLM = intercept/2. Three windows were tried: 1–10, 2–20 and 0.5–5 µm.

**Validation (exact limit):** with n_c = n_bulk, R_c,TLM = −1.4×10⁻¹² Ω·µm, against an exact value of 0. The slope equals R_sheet = 756.894 Ω/sq to 10⁻⁹. It passes.

**What came out**
1. **R_extra is not a fixed number on this profile.** The 1/(1 + x/λ) tail makes δn ∝ 1/x, so ∫(1/σ − 1/σ_b)dx grows like ln L_j. The src value at L_j = 1 µm is an arbitrary cut: for Al it changes from −542 to −2407 to −5283 Ω·µm at 1, 10 and 100 µm.
2. **TLM does pick up the junction.** It does not separate it out. R_c,TLM ranges from 0.48× (Al) to 1.13× (Cu) of the src R_extra for Al, Ag, Cu and Au. The kill condition ("absorbs < 10 % for every metal") is **not hit**. The extracted value depends on the fit window by a factor of about 2–3, because the log tail leaks into both the slope and the intercept. The apparent R_sheet ranges from 397 to 2276 Ω/sq, against a true 757 Ω/sq.
3. **Pt is a separate case.** Its p–n crossing sits at x = 5λ = 1.25 µm, which is outside the src 1 µm integration window. The src R_extra of +173 Ω·µm misses the junction, and the value is +4439 Ω·µm at 10 µm. In the TLM, short devices are p-type throughout because the two tails overlap. R(L) is then strongly non-linear: the fit residual is up to 1.9 kΩ·µm, and the sign of R_c,TLM depends on the window.
4. The fit residuals are large for Al, Au and Pt (240–1900 Ω·µm) and small for Cu (14 Ω·µm). This gives a test the model can fail: **the model predicts visible curvature in R_tot(L) for strongly doping contacts**. A published TLM dataset can confirm or refute it.

**Metric:** the kill condition is not hit. I1 has no data comparison yet, so it is not PAPER-READY. There is one candidate claim: "a contact-doping tail with δn ∝ 1/x makes the TLM R_c window-dependent and bends R_tot(L)". It needs (a) a novelty check against the TLM-artefact literature and (b) a digitised R_tot(L) dataset.

**Caveats:** linear superposition of the two tails overshoots n at the contact edge for short L, by the factor (n_c − n_b)·f(L). The δn ∝ 1/x tail is the src model's choice (Khomyakov 2009 asymptotics). A screened (exponential) tail would remove the log growth, so finding 1 is about the profile and does not hold generally. With R_int = 0, the absolute R_c,TLM values are junction-only.
